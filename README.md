# Web Application Security

## Web Application Security Configuration Review

A professional portfolio documenting structured manual reviews of web application security configurations.

The focus is on identifying security misconfigurations, documenting findings and providing clear, actionable recommendations.

## Areas of Focus

### 1. Security Headers
Review of HTTP response security headers, including:

- Content-Security-Policy (CSP)
- Strict-Transport-Security (HSTS)
- X-Content-Type-Options
- Referrer-Policy
- Other relevant browser security controls

### 2. TLS / HTTPS
Review of HTTPS and TLS configuration, including:

- TLS protocol versions
- Certificate validity and configuration
- HTTPS enforcement and redirection
- Potentially insecure configuration settings

### 3. Information Disclosure
Review of publicly exposed information, including:

- Server and technology version disclosure
- Verbose error messages
- Unnecessary HTTP response information
- Publicly accessible configuration information

## Audit Methodology

Reviews are designed to be structured, evidence-based and limited to an agreed scope.

Testing is conducted only on systems owned by the reviewer or where explicit authorisation has been obtained.
